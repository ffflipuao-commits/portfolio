# AIGC 商业视觉栏目重设计规格

## 目标

重做作品集中的「AI平面视觉设计」「电商与数字化设计」「商业插画设计」，删除「色彩与材质实验」。新内容统一采用已确认的 A 方向——国际商业编辑风，提升作品真实性、完整度以及与 AIGC 视觉设计岗位的匹配度。

## 统一视觉语言

- 延续网站黑色背景与紫色强调色，不改动首页和已上线的海外人像栏目。
- 作品图片采用杂志级构图、克制排版、真实材质和明确商业使用场景。
- 所有人物、产品、品牌与活动均为原创虚构设定，不暗示真实客户合作。
- 页面保留中英双语标题；中文说明职责、流程和应用场景，语气符合应届生作品集。
- 每个栏目采用一张横向主视觉加两张应用延展图，移动端改为单列。

## 栏目一：AI平面视觉设计

项目设定为原创国际文化活动「New Perspectives / 新视界」视觉系统。

作品内容：

1. 国际文化活动主海报：编辑式人物拼贴、鲜明色块、网格化英文排版。
2. 城市户外灯箱应用：展示主视觉在真实街区媒介中的适配。
3. 社交媒体视觉矩阵：展示方形帖文与竖版故事页延展。

页面说明突出概念提炼、版式层级、人物素材控制、系列一致性和跨尺寸适配，不虚构传播数据。

## 栏目二：电商与数字化设计

项目设定为原创海外香氛生活方式品牌「Serein Atelier」电商视觉。

作品内容：

1. 香氛产品主视觉：真实玻璃、液体、纸材和自然光质感。
2. 电商促销与商品详情组合：展示卖点层级、产品组合和信息排版。
3. 移动端购物界面：展示首页、商品详情和购物袋的核心页面。

页面说明突出商品图生成、材质校验、信息层级、跨端适配以及从营销视觉到购物界面的完整链路。品牌为作品集虚构概念，不使用虚构销量或转化率。

## 栏目三：商业插画设计

项目设定为原创「Atlas Notes / 城市漫游笔记」国际旅行与城市文化插画系列。

作品内容：

1. 城市文化杂志封面：人物、建筑与地方元素的编辑插画。
2. 旅行城市海报组：两至三座虚构或泛化城市的系列化构图。
3. 包装与文创应用：明信片、手提袋或旅行手册的落地展示。

页面说明突出风格设定、色板控制、系列统一、细节修正与商业延展。插画保持原创，不模仿具体在世艺术家。

## 删除与编号

- 完整删除「色彩与材质实验」HTML 内容，不保留入口或旧卡片。
- 原项目编号在删除后连续排列，不出现跳号。
- 不删除现有详情页文件，以免影响其他历史链接；主作品集不再引用被替换的旧详情页。

## 实现结构

- 新增三组原创位图素材，存入 `images/`，使用语义化英文文件名。
- 在 `ai-portfolio.html` 中新增统一的商业案例网格与图片覆盖层样式。
- 直接替换三个旧栏目的 HTML，不叠加旧内容。
- 所有图片写明中文替代文本并采用延迟加载。

## 验收标准

- 三个栏目全部显示新项目设定与新图片，旧 CSS 占位缩略图不再出现。
- 「色彩与材质实验」在 HTML 和线上页面中均不存在。
- 桌面端主视觉层级清晰；390px 手机端无横向溢出并为单列布局。
- 所有新增图片线上返回 HTTP 200，栏目编号连续。
- GitHub Pages 线上回读包含三个新项目标题与对应图片路径。
