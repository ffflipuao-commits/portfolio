# 鸢都文创 · 品牌VI与产品设计规范

## 一、项目概述

- **品牌名**：鸢都文创（Yuandu Wenchuang）
- **核心意象**：潍坊纸鸢（风筝）= 自由、飞翔、连接天地
- **设计哲学**："古韵新飞" — 传统风筝骨架为筋骨，现代设计语言为羽翼
- **风格融合**：传统国风 + 新国潮 + 清新文艺 + 民俗民间
- **目标受众**：全产品线（文旅纪念品 / 中高端礼品 / 年轻潮品）

---

## 二、Logo 设计（V8定稿版）

### 2.1 标志图形

V8沙燕纸鸢抽象标志：
- **硬翅元宝形**双翼，竹骨框架线（上横撑/下横撑/斜撑/翼缘）
- **圆形头部** + 鼓起面颊 + 三角形短喙 + 如意形眼 + 眉弓
- **短圆橄榄形身体** + 脊线 + 3枚菱形纹 + 腰带弧线
- **剪刀燕尾**：两片宽阔尾翼 + 中间V形分叉 + 横带装饰 + 鎏金流苏结
- **如意冠**：头顶三连如意珠
- **外圈**：单环边框 + 四角小云纹

### 2.2 标准字

- **中文标准字**：楷体（KaiTi）「鸢都文创」，字间距8-10px
- **英文标准字**：Georgia衬线体「YUANDU WENCHUANG」，字间距3-4px

### 2.3 标准色

| 色名 | HEX | CMYK | 用途 |
|------|-----|------|------|
| 朱砂红 | #C41E2B | C0 M85 Y78 K23 | 主色，Logo翼面，端午主题 |
| 藏蓝 | #1A3C6D | C76 M45 Y0 K57 | 主色，Logo身体/头部，高端底 |
| 鎏金 | #D4952B | C0 M30 Y80 K17 | 辅色，纹样点缀，高亮点睛 |
| 石绿 | #4B8B7F | C65 M0 Y40 K45 | 辅色，自然清新，辅助底纹 |
| 桃红 | #E85D8B | C0 M60 Y25 K9 | 民俗色，活泼氛围 |
| 宣纸白 | #F5E6D3 | C0 M6 Y14 K4 | 底色，留白，质感 |

### 2.4 标准组合

- **组合A（横式·主用）**：标志左 + 中文右 + 英文下
- **组合B（竖式）**：标志上 + 中文竖排下
- **组合C（反白）**：藏蓝底 + 反白图形 + 鎏金点缀

### 2.5 使用规范

- 安全空间：标志四周保留 1/2标志高度
- 最小尺寸：横式30mm（印刷）/ 120px（屏幕），竖式25mm / 100px
- 反白版本仅在藏蓝底色或深色背景上使用

- **组合拼贴**：2-3个图形组合，用于海报/礼盒
- **线稿烫金**：金色单线版本，用于深色底/烫金工艺

## 四、三张主题海报

### 4.1 海报一：品牌形象「鸢都文创」
- 渐变藏蓝底 + 反白V8完整Logo + 「古韵新飞·匠心文创」

### 4.2 海报二：端午主题「鸢飞端阳·粽香千里」
- 宣纸白渐变底 + 原色V8 Logo + 粽子/香囊元素
- 文字：纸鸢乘风起，艾蒲满城香，一鸢一粽寄安康
- 标签：端午限定、香囊礼盒
- 调性：节日氛围，温暖亲切

### 4.3 海报三：非遗传承「千年纸鸢」

- 十鸢群像 + 非遗传承/匠心手作标签
- 调性：文化厚度，庄重典雅

## 五、包装设计系统（五件套）

### 5.1 精装礼盒（天地盖）
- 盒盖：藏蓝底 + 反白V8 Logo居中 + 云纹暗底
- 盒身：菱形纹连续环带 + 产品信息段
- 结构：天地盖，含内衬，可容纳香囊×2 + 书签×1

### 5.2 手提袋
- 正面：宣纸白底 + 原色V8 Logo居中 + 标准字
- 侧面：藏蓝底 + 鎏金竖排「鸢都文创」+ 菱形点装饰
- 材质：白卡纸/牛皮纸，双提手

### 5.3 小产品包装盒
- 香囊盒：桃红底 + 反白V8 Logo
- 明信片套：石绿底 + 辅助图形满铺 + 反白标准字

### 5.4 包装纸/丝巾
- 60×60cm 方形
- 十鸢辅助图形 + 云纹 + 草叶纹满铺，透明度15-25%
- 中心预留徽标区域

### 5.5 标签/吊牌/贴纸
- **品牌吊牌**：宣纸白底 + 打孔 + 挂绳 + V8 Logo
- **封口贴纸**：圆形，三色（朱砂红/藏蓝/鎏金），Logo反白
- **说明标签**：宣纸白底 + 鎏金边框 + 产品信息
- **织唛布标**：藏蓝底反白标准字，用于香囊/丝巾

## 六、端午香囊「鸢香」

### 6.1 设计
- **外形**：纸鸢燕尾造型（8×12cm含流苏）
- **正面**：V8 Logo头部 + 菱形纹腰带 + 云纹点缀 + 竖排「鸢都」字
- **背面**：艾草纹样 + 回纹线 +「端午·安康」+「DUANWU」
- **三色版**：朱砂红（端午主推）、藏蓝（经典）、石绿（自然）

### 6.2 工艺材质
- 面料：丝绸 + 纯棉内衬
- 填充：艾草 + 白芷 + 藿香 + 薄荷
- 工艺：丝印 + 手工缝制 + 编织挂绳 + 石绿玉珠收口

### 6.3 使用场景
- 随身佩带（挂包/腰间）
- 车内悬挂（驱蚊避虫）
- 节庆送礼（端午礼盒配套）
- 家居装饰（挂门楣/窗边）
